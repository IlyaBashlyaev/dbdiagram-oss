# Summary 2023-08-19 to 2025-08-21 - Developer NomadRazor (Peter Shcherbakov)

Over this period the developer built out the diagram editor from its first layout and redraw work into a more complete tool. Table and relation display, color customization, tooltips and multi-schema support were added in 2023. In 2024 the focus moved to editor features (import, export, fit-to-view, touch support), repository handling with multiple folders, and many fixes to table positioning and colors. In 2025 a multiline comment bug was fixed and several additional SQL import types were added. Some commit messages ("bla bla bla", "none") carry no information and are not listed individually.

- Auto-layout algorithm first version and correct redraw of references (f67eba4, 8e07727)

- Relation type is shown (89b40cc)
