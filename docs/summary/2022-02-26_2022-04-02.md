# Summary 2022-02-26 to 2022-04-02 - Developer TruDan (Dan Spiteri)

In this period the project was started from scratch and grew into a working database diagram editor. The first days brought the initial setup, a readme, syntax highlighting in the editor and persistence of the graph layout. In March the diagram rendering was moved away from JointJS to a self-built SVG renderer, which made table dragging, pan and zoom, relationship lines and persistence of positions work. Further additions were multiple-file support, a preferences dialog with a theme chooser, error display in the editor, table groups, a zoom tool, draggable references, a background grid, tooltips and locating elements in the editor by double click. A deployment to GitHub Pages was set up and the readme received a live demo link.
